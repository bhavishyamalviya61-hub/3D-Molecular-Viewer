
# 3D Molecular Viewer

A beginner-friendly Computational Chemistry project built using Python.

## Features
- Interactive 3D molecular visualization
- Molecular formula and molecular weight
- Atom and bond count
- Multiple example molecules

## Technologies
- Python
- Streamlit
- RDKit
- py3Dmol

## Installation

Create and activate a virtual environment, then run:

```bash
python -m pip install -r requirements.txt
```

## Run the project

```bash
python -m streamlit run app.py
```

## Example molecules
- Water
- Methane
- Ammonia
- Carbon dioxide
- Ethanol
- Benzene
- Glucose

## Purpose
Created as a beginner-level college project for Computational Chemistry.
